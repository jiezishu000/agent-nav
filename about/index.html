关于 Agent Nav

AI Agent 导航站 — 发现最好用的 AI Agent 工具

项目简介

Agent Nav 是一个精心整理的 AI Agent 导航站，收录了 340+ AI Agent 工具，覆盖 20+ 分类。 我们从 GitHub 高星仓库、社区推荐和官方渠道收集数据，每月更新，帮助开发者快速发现和选择适合的 AI Agent 工具。

数据来源

  • awesome-ai-agents-2026 — 340+ AI Agent 收录
  • Agentic-Index — Agent 生态全景
  • GitHub 高星仓库实时追踪
  • 社区贡献与推荐
